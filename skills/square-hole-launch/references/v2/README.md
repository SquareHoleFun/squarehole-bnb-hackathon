# Format 2 worked examples, configurations and presets

> Generated by `skills/square-hole-launch/scripts/build-references.mjs` from the JSON files here; `pnpm check:launch-skill` reads every one against its network's menu; do not edit it by hand.

For the twelve Sepolia kits, [start from a kit](kits/README.md): use its settings file, Load settings, then choose the verified listing. Each worked guide includes the exact registry row and its loading instructions. L1's ten other kit filenames are unchanged; both hidden kits have public settings templates and plan manifests. Alchemist remains pending and refused.

For Frog Kiln and Paper Certificates, in **Load settings** pick the public settings file and its `-plan.json` together. Then select the plan's 12 variant PNG pictures from `art/items/` and `plan.csv` together in **Images + traits**, or a folder containing just those files. Create checks the settings/plan binding, plan count and sorted trait table, deals fresh numbers and salts, and replaces the template marker with a new private root. Save the reveal file privately before Create. The public template is not create calldata.

The creator adds the art without an AI browser agent. Keep the reveal file outside any folder an AI can read; never paste it into chat. Keep item pictures, assignments, salts and reveal data out of this skill and every public bundle until reveal. Load settings keeps the file's own hidden picture; `art/hidden.svg` is a public placeholder by design. The launch flow still takes no SVG upload. Paper Certificates uses Gold Certificates and specimen number 0; the page deals its 1,929 item numbers privately.

Payouts are claim-only: each owner claims its own funds. Owner claims have no minimum or tip. Wallets, contracts and EIP-7702 owners use the same owner claim entry. The FIT and platform Safes claim their own fee shares. Collection and protocol-step tips are separate from owner payouts.

The draft JSON files below exercise the offline demo menu; they are not app settings downloads or live deployments. Items use explicit Keep, BuyBackBurn or Depth policies. Shops use seed, pick receipts and the selected sellers fee funding up to a fixed ceiling. A same-price-coin pile can receive pending fees after graduation. Pile redemptions leave 0 or 500 basis points; the last redeemer takes the balance. Exit Liquidity has 404 open signs, Grow buyers and item payouts with BuyBackBurn inside on sellers. A preset keeps its id and version off chain. Refresh the listing raise, quote and both mined salts before Create.
