# Rent Free (RENT)

> Generated by `scripts/kit-references.mjs`; edit the guide there, then run `pnpm launch-skill:write`.

500 open houses, RENT. Buyers pay every house in the price coin: outside shares are claimable and inside shares buy RENT and burn it. Sellers burn RENT. Rent and property tax are jokes, not real property income.

## Start from this kit

Each of the 500 houses has its own picture and its own 3D model (a GLB). The settings file carries every picture, every model and the public reveal list. After **Load settings**, add the bundle's `items/` files together: `1.png` … `500.png`, `1.glb` … `500.glb` and `traits.csv` (**Images + models + traits**, or the folder). Create checks every model and refuses the pictures without their models. The unbound settings use ETH listing 0. Supply a verified tUSDC priceListing when building, or select the verified tUSDC listing after Load settings. The locked description is coin-neutral; no rewrite is needed when changing the price coin. tUSDC is an unbacked Sepolia test coin; this setup makes no promise of value.

1. Review public bindings with the integrator, then rebuild from the repository root: `node scripts/kits/bundle.mjs rent-free` (add `--bindings PUBLIC_JSON` when needed). A build alone does not prove any address is deployed.
2. Use the settings file `examples/boxes/rent-free/build/rent-free-boxspec-v2.json`. In Create on Sepolia, choose **Load settings** and select that file. This is the app download, not a skill draft or the registry JSON below.
3. Choose the listing for **tUSDC** by verified chain and token address. Loading ETH listing 0 does not select a test token. Resolve every slot in build/inventory.json, refresh the listing raise, and recheck the seed and creator buy in their own units.
4. Compare name, ticker, contents, art mode, fees, deadline and pick fee with the recipe. Confirm the opening time (zero means next block), art rights and final overview. The founder signs; prepare offline Safe batches for a shop.

Payouts are claim-only. Registry ready means the recipe has a test life; it is not evidence of Sepolia deployment. Refresh mutable listings before Create. Keep monetary values as raw decimal strings.

Public example art can be served by the project node. New box collections become listable only after graduation and take-out; Test Junk and Bent Cans are the outside full sets for these shops. Videos use captions only.
