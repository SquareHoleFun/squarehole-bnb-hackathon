## Start from this kit

Use the public settings template and its plan manifest below, then the specimen-0 plan route: plan.csv plus the 12 PNGs in art/items/. Every picture retains specimen number 0; the page randomly assigns ids 1–1929. Do not load the 776 MB numbered rendition (above the 256 MiB limit). The founder distributes tGOLD directly.

1. The creator, without an AI browser agent, opens Create on Sepolia. In **Load settings**, pick `examples/boxes/paper-certificates/settings/paper-certificates-boxspec-v2.json` and `examples/boxes/paper-certificates/settings/paper-certificates-plan.json` together. These are a public settings template and its plan manifest, not a private edition or an assistant draft.
2. Then select the plan's 12 variant PNG pictures from `examples/boxes/paper-certificates/art/items/` and `examples/boxes/paper-certificates/plan.csv` together in **Images + traits**, or a folder containing just those files. Create checks the settings/plan binding, plan count and sorted trait table, deals fresh numbers and salts, and replaces the template marker with a new private root. Never submit the public template directly as create calldata or substitute public assignments or deterministic salts.
3. Save the reveal file privately before Create, outside any folder an AI can read; never paste it into chat. Keep item pictures, assignments, salts and reveal data out of this skill and every public bundle until reveal. Load settings keeps the file's own hidden picture; `art/hidden.svg` is a public placeholder by design. The launch flow still takes no SVG upload. Prepare drand and the reveal worker before opening.
4. Choose the listing for **tGOLD** by verified chain and full token address; the template's ETH listing 0 is not that binding. Refresh the listing raise and quotes, compare the overview with this recipe, and confirm opening time and art rights. Only the founder signs; this worked example is not evidence of a live deployment.

Payouts are claim-only. Registry ready means the recipe has a test life; it is not evidence of Sepolia deployment. Refresh mutable listings before Create. Keep monetary values as raw decimal strings.

Public example art can be served by the project node. New box collections become listable only after graduation and take-out; Test Junk and Bent Cans are the outside full sets for these shops. Videos use captions only.
