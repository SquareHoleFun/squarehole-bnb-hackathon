# The Junkyard (TRASH)

> Generated by `scripts/kit-references.mjs`; edit the guide there, then run `pnpm launch-skill:write`.

The Junkyard, TRASH: a creator Safe seeds 180 million TRASH and ten outside NFTs. Buyers pay holders in the price coin. Sellers fill the shop up to 2x its seed, then pay holders. Picks cost twice the give price; 10% weekly and 2.5% per collection, with a seven-day delay.

## Start from this kit

The base registry below uses four local-life scrap collections (4+2+2+2 starters). The Sepolia kit explicitly substitutes five Test Junk collections: bent-cans, lost-cogs, split-boots, cracked-mugs and tangled-wires, ids 1–2 each, tier 0. Keep that distinction visible. Bind all five deployed addresses and the creator Safe. Type those starter ids in Load settings. Re-quote the 0.3 ETH-equivalent creator buy in tGOLD using the current raises; it is not 0.3 tGOLD. The founder signs offline Safe batches for creation, exact starter approvals and loading. See docs/runbooks/junkyard-launch.md.

1. Review public bindings with the integrator, then rebuild from the repository root: `node scripts/kits/bundle.mjs junkyard` (add `--bindings PUBLIC_JSON` when needed). A build alone does not prove any address is deployed.
2. Use the settings file `examples/boxes/junkyard/settings/junkyard-boxspec-v2.json`. In Create on Sepolia, choose **Load settings** and select that file. This is the app download, not a skill draft or the registry JSON below.
3. Choose the listing for **tGOLD** by verified chain and token address. Loading ETH listing 0 does not select a test token. Resolve every slot in build/inventory.json, refresh the listing raise, and recheck the seed and creator buy in their own units.
4. Compare name, ticker, contents, art mode, fees, deadline and pick fee with the recipe. Confirm the opening time (zero means next block), art rights and final overview. The founder signs; prepare offline Safe batches for a shop.

Payouts are claim-only. Registry ready means the recipe has a test life; it is not evidence of Sepolia deployment. Refresh mutable listings before Create. Keep monetary values as raw decimal strings.

Public example art can be served by the project node. New box collections become listable only after graduation and take-out; Test Junk and Bent Cans are the outside full sets for these shops. Videos use captions only.
