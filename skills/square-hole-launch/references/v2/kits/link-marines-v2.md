# Link Marines (MARINE)

> Generated by `scripts/kit-references.mjs`; edit the guide there, then run `pnpm launch-skill:write`.

The Sepolia Link Marines example is version 2: 420 open marines, MARINE. Both fee sides pay the box share (10 of 15 parts) as equal rations in the price coin. Outside owners claim tLINK; inside shares deepen the box’s own pool (Items/Depth). Royalties of 2.5% feed the same fee handling.

## Start from this kit

Each of the 420 marines has its own portrait and no 3D model (2D), with nine traits: Rank, Squad, Face, Eyes, Grooming, Collar, Mouth, Prop and Wall. The twelve ranks and 35 squads follow the original rule. Build all 420 numbered pictures and the public reveal list. Rank changes no ration. The unbound settings use ETH listing 0; supply a verified tLINK priceListing or choose that listing after Load settings. The locked description is coin-neutral. tLINK is an unbacked Sepolia test coin; there is no promise of value. Its local contract and browser lives cover both sides’ rations, an owner’s claim in the price coin, the inside shares going to the box’s own pool and the royalty; that is not a Sepolia deployment. After creation, prepare open reveals from the created box’s own download.

1. Review public bindings with the integrator, then rebuild from the repository root: `node scripts/kits/bundle.mjs link-marines-v2` (add `--bindings PUBLIC_JSON` when needed). A build alone does not prove any address is deployed.
2. Use the settings file `examples/boxes/link-marines-v2/build/link-marines-v2-boxspec-v2.json`. In Create on Sepolia, choose **Load settings** and select that file. This is the app download, not a skill draft or the registry JSON below.
3. Choose the listing for **tLINK** by verified chain and token address. Loading ETH listing 0 does not select a test token. Resolve every slot in build/inventory.json, refresh the listing raise, and recheck the seed and creator buy in their own units.
4. Compare name, ticker, contents, art mode, fees, deadline and pick fee with the recipe. Confirm the opening time (zero means next block), art rights and final overview. The founder signs; prepare offline Safe batches for a shop.

Payouts are claim-only. Registry ready means the recipe has a test life; it is not evidence of Sepolia deployment. Refresh mutable listings before Create. Keep monetary values as raw decimal strings.

Public example art can be served by the project node. New box collections become listable only after graduation and take-out; Test Junk and Bent Cans are the outside full sets for these shops. Videos use captions only.
