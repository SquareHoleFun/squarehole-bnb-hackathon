# One-collection shop (SHOP)

> Generated by `scripts/kit-references.mjs`; edit the guide there, then run `pnpm launch-skill:write`.

SHOP accepts only Test Junk Bent Cans. The creator Safe supplies ids 3–12 and 2 million SHOP, enough for two gives at 1 million each. Picks cost 2 million. No curator: nobody can add collections. Buyers pay holders; sellers fill the shop to 2x seed, then pay holders.

## Start from this kit

Bind the deployed bent-cans collection and creator Safe. Mint ids 3–12 to that Safe, separately from Junkyard ids 1–2, and type 3–12 in Load settings. Preserve No curator. Use native listing 0, a freshly quoted 0.01 ETH creator buy, and offline Safe batches. The collection limit is 2.5% of the weekly starting budget with the cheapest-give floor; the global weekly limit is 10%. The last NFT stays.

1. Review public bindings with the integrator, then rebuild from the repository root: `node scripts/kits/bundle.mjs one-collection-shop` (add `--bindings PUBLIC_JSON` when needed). A build alone does not prove any address is deployed.
2. Use the settings file `examples/boxes/one-collection-shop/settings/one-collection-shop-boxspec-v2.json`. In Create on Sepolia, choose **Load settings** and select that file. This is the app download, not a skill draft or the registry JSON below.
3. Choose the listing for **SepETH** by verified chain and token address. Loading ETH listing 0 does not select a test token. Resolve every slot in build/inventory.json, refresh the listing raise, and recheck the seed and creator buy in their own units.
4. Compare name, ticker, contents, art mode, fees, deadline and pick fee with the recipe. Confirm the opening time (zero means next block), art rights and final overview. The founder signs; prepare offline Safe batches for a shop.

Payouts are claim-only. Registry ready means the recipe has a test life; it is not evidence of Sepolia deployment. Refresh mutable listings before Create. Keep monetary values as raw decimal strings.

Public example art can be served by the project node. New box collections become listable only after graduation and take-out; Test Junk and Bent Cans are the outside full sets for these shops. Videos use captions only.
