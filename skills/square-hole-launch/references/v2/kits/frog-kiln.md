## Start from this kit

Use the public settings template and its plan manifest below, then the kit plan.csv with the 12 PNGs in art/items/. Require a tFROG listing admitted with addWithBurn and checked burn(uint256), selector 0x42966c68. A lock-only listing does not meet this example.

1. The creator, without an AI browser agent, opens Create on Sepolia. In **Load settings**, pick `examples/boxes/frog-kiln/settings/frog-kiln-boxspec-v2.json` and `examples/boxes/frog-kiln/settings/frog-kiln-plan.json` together. These are a public settings template and its plan manifest, not a private edition or an assistant draft.
2. Then select the plan's 12 variant PNG pictures from `examples/boxes/frog-kiln/art/items/` and `examples/boxes/frog-kiln/plan.csv` together in **Images + traits**, or a folder containing just those files. Create checks the settings/plan binding, plan count and sorted trait table, deals fresh numbers and salts, and replaces the template marker with a new private root. Never submit the public template directly as create calldata or substitute public assignments or deterministic salts.
3. Save the reveal file privately before Create, outside any folder an AI can read; never paste it into chat. Keep item pictures, assignments, salts and reveal data out of this skill and every public bundle until reveal. Load settings keeps the file's own hidden picture; `art/hidden.svg` is a public placeholder by design. The launch flow still takes no SVG upload. Prepare drand and the reveal worker before opening.
4. Choose the listing for **tFROG** by verified chain and full token address; the template's ETH listing 0 is not that binding. Refresh the listing raise and quotes, compare the overview with this recipe, and confirm opening time and art rights. Only the founder signs; this worked example is not evidence of a live deployment.

Payouts are claim-only. Registry ready means the recipe has a test life; it is not evidence of Sepolia deployment. Refresh mutable listings before Create. Keep monetary values as raw decimal strings.

Public example art can be served by the project node. New box collections become listable only after graduation and take-out; Test Junk and Bent Cans are the outside full sets for these shops. Videos use captions only.
